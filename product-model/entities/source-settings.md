# Source settings

Preferences for choosing among devices and apps.

## Information kept

- **Order** — The person’s preferred source order.
- **First choices** — Optional first source for each supported reading.
- **Totals** — Which sources Google adds up: all, Google sources, or worn Google devices; all by default.
